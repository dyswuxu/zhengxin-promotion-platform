## 1. 平台概述

### 1.1 什么是"新品作战平台"？

这是一个专门为正新鸡排新品推广而设计的**战役指挥系统**。不是普通的后台管理工具，而是让团队像打一场战役一样来推进新品上市。

### 1.2 核心理念

- **战役化**：每一次新品推广都是一场30天的战役
- **阶段化**：清晰的四个阶段（预热→强曝光→套餐放大→裂变复购）
- **竞争化**：区县PK、门店龙虎榜，激发团队斗志
- **AI驱动**：AI自动生成推广方案、内容、数据复盘

### 1.3 四个战役阶段

| 阶段 | 时间 | 核心目标 | 代表动作 |
|------|------|----------|----------|
| 🔥 上市预热 | Day 1-3 | 造势、预埋 | 市场调研、竞品分析、预热物料准备 |
| ⚡ 强曝光 | Day 4-10 | 快速拉新、提高声量 | 大规模推广、KOL投放、门店POP |
| 📦 套餐放大 | Day 11-20 | 提升客单价、增加套餐率 | 套餐组合优化、连带销售、会员活动 |
| 🚀 裂变复购 | Day 21-30 | 私域激活、复购沉淀 | 裂变活动引爆、私域社群激活 |

## 2. 首页 · 战役指挥台

> 这是你每天打开平台看到的第一眼。要像战役指挥中心一样，一眼看战场全局。

### 2.1 战役头部 Banner

页面最上方，显示**当前进行中的新品战役**：

- **战役名称**：如"蔬香鸡腿排新品战役"
- **Day X · 当前阶段**：如"Day 7 · 强曝光阶段"（带颜色徽章）
- **参与情况**：如"全国11区县同步推进中"

右侧展示四个**核心指标大卡片**：

| 指标 | 说明 | 趋势颜色 |
|------|------|----------|
| 当前销量 | 累计销售份数 | ↑绿色=上升，↓红色=下降 |
| 套餐率 | 套餐订单占比 | 同上 |
| 连带率 | 平均每单件数 | 同上 |
| 执行率 | 门店执行达标比例 | 同上 |

### 2.2 30天战役进度条

横向时间轴展示四个阶段，每个阶段显示日期范围。

- **当前阶段高亮**，带有发光效果
- **点击任意阶段**，下方展开该阶段的核心任务清单
- 清晰回答"现在在哪"、"还剩多久"、"要做什么"

### 2.3 今日作战任务

三栏并列，展示今天不同层级的任务：

| 总部动作 | 区县动作 | 门店动作 |
|----------|----------|----------|
| 发布朋友圈预热文案 | 门店POP物料检查 | 早会新品推荐话术 |
| 对接KOL投放排期 | 店员话术抽查 | 套餐组合推荐 |
| 审核区域执行报告 | 区域PK战报收集 | 闭店数据汇报 |

每个任务右侧有状态标签：**已完成**（绿色）/ **进行中**（橙色）/ **未开始**（灰色）

### 2.4 区县PK榜

排行榜展示各区县的实时排名，激励团队竞争。

- 🏆 第一名（金色）
- 🥈 第二名（银色）
- 🥉 第三名（铜色）
- 显示：区县名、销量、套餐率、执行率、排名变化（↑上升/↓下降）

### 2.5 门店执行热力图

网格展示各门店执行状态，颜色一目了然：

- 🟢 **绿色** = 优秀（执行率≥85%）
- 🟡 **黄色** = 注意（执行率70-84%）
- 🔴 **红色** = 掉队（执行率<70%）

### 2.6 AI内容工厂

展示AI正在/已经生成的内容：

- 海报（已生成/生成中）
- 视频（已生成/生成中）
- 音频（已生成/生成中）
- 文案（已生成/生成中）

## 3. 新品中心

> 管理所有新品推广项目，了解每个新品的当前状态。

### 3.1 新品列表

按状态筛选：

- 全部 / 推广中 / 爆发 / 复盘 / 草稿 / 已结束

每个新品卡片显示：

- 状态标签（如"推广中"）
- 产品名称
- 价格和毛利率
- 上市日期和区域

### 3.2 新建新品

点击"新建新品"按钮，进入 **AI战略生成器**（见下一章）。

### 3.3 导入/导出新品的Excel表格

- **导出门店**：下载包含所有新品的Excel表格
- **导入门店**：上传Excel批量添加新品（需下载模板）
- **下载模板**：获取标准导入表格格式

### 3.4 新品状态流转

```
草稿 → 未开始 → 推广中 → 爆发 → 复盘 → 已结束
```

## 4. AI战略生成器

> 输入产品信息，AI自动生成完整的30天新品推广方案。

### 4.1 Step 1 · 新品情报录入

左侧填写表单：

| 字段 | 说明 | 必填 |
|------|------|------|
| 产品名称 | 如"藤椒鸡排" | ✅ |
| 产品类别 | 鸡排/小吃/饮品/套餐 | |
| 售价 | 元 | ✅ |
| 成本 | 元 | ✅ |
| 目标人群 | 18-30岁白领、学生等 | |
| 核心卖点 | 每行一个卖点 | |
| 上市时间 | 选择日期 | |
| 推广区域 | 全国/华东/华南等 | |

右侧**实时预览**：显示AI生成的一句话定位

### 4.2 Step 2 · 战略礼包生成

AI生成**五大标准包**，以卡片形式展示：

| 礼包 | 图标 | 内容 |
|------|------|------|
| 新品上市卡 | 🎯 | Day1-30完整上市节奏与执行路线图 |
| 门店卖法包 | 🏪 | 店员话术、推荐技巧、套餐组合 |
| 新品传播包 | 📢 | 海报、视频、文案一站式产出 |
| 新品PK机制 | ⚔️ | 区县PK、门店龙虎榜、个人销冠赛 |
| 30天复盘机制 | 📊 | 数据追踪、定期复盘、经验沉淀 |

每个卡片显示生成状态：**✓ 已生成** / **⟳ 生成中** / **○ 待生成**

### 4.3 Step 3 · 内容预览

视觉化预览将要生成的各类内容：

- **海报**：彩色预览卡片，显示主标题和副标题
- **视频**：视频封面预览，显示时长
- **音频**：播放条UI，显示歌词
- **文案**：社交媒体帖子预览（朋友圈/小红书风格）

### 4.4 Step 4 · 启动战役

点击大按钮「**启动30天新品战役**」一键启动：

- 自动创建战役
- 自动生成每日任务
- 自动启动区县PK
- 自动分配门店任务
- 自动创建数据看板

## 5. 作战任务

> 30天战役的推进中心，所有任务的统一管理。

### 5.1 任务筛选

按状态筛选：**全部 / 未开始 / 进行中 / 已完成 / 延迟 / 异常**

按类型筛选：**全部类型 / 上新执行 / 物料张贴 / 促销执行 / 数据回传**

### 5.2 任务卡片

每个任务卡片显示：

- **任务描述**：如"Day7：发布冠军门店海报"
- **关联新品**：哪个新品的任务
- **关联门店**：哪家门店执行
- **截止日期**：还有多久到期（快到期显示红色警告）
- **当前状态**：已完成/进行中/未开始
- **操作按钮**：开始 / 完成 / 标记异常

### 5.3 导出任务

点击"导出"按钮，下载所有任务的Excel表格，便于线下跟踪。

## 6. 战况数据中心

> 新品经营的数据分析中心，每个图表下方都有AI自动生成的经营判断。

### 6.1 核心指标

- **新品销量**：按时间趋势展示
- **新品占比**：新品销量占总销量的比例
- **套餐率**：套餐订单占比
- **连带率**：平均每单购买件数
- **复购率**：重复购买新品的顾客比例
- **区县执行率**：各区县的执行达标情况

### 6.2 AI经营判断

每个图表下方，都有一句**AI自动生成的分析文字**，例如：

> "夜宵套餐对套餐率提升明显，建议重点关注18:00-22:00时段的套餐推广。"

> "A区县执行率低，主要问题在门店推荐不足，建议增加该区域培训频次。"

### 6.3 热力图

门店执行热力图，红色/黄色/绿色一目了然看到哪些门店掉队、哪些门店优秀。

## 7. 战役复盘

> 每轮新品战役结束后的总结沉淀，为下一轮提供经验。

### 7.1 案例库

分为**成功案例**和**失败案例**两类：

每个案例记录：

- **产品名称**
- **评分**（0-100）
- **关键成功/失败因素**
- **经验教训**
- **复盘日期**

### 7.2 AI优化建议

根据历史数据，AI自动生成优化建议，如：

- "预热期重要性：有完整7天预热期的新品成功率比没有预热的高出47%。建议所有新品必须包含T-7的预热动作。"
- "定价策略：定价在15-25元区间的新品最受欢迎，毛利率应控制在55%-65%之间。"

### 7.3 统计概览

- 成功案例数
- 失败案例数
- 平均评分

## 8. 门店管理

> 管理所有门店信息，支持批量导入导出。

### 8.1 门店列表

每个门店卡片显示：

- **门店名称**
- **所属区域**（华东/华南等）
- **区县**
- **店长姓名**
- **联系电话**
- **状态**（活跃/非活跃）

支持**搜索门店名称、区县、店长**。

支持**按区域筛选**门店。

### 8.2 批量导入

点击"选择Excel文件"，上传包含门店信息的.xlsx表格批量导入。

**导入说明：**

- 第一行为表头，请勿修改
- 必填字段：门店名称、所在区域
- 可选字段：城市、区县、地址、店长姓名、联系电话
- 区域填写规范：华东、华南、华北、华中、西南、西北、东北

### 8.3 导出门店/下载模板

- **导出门店**：下载包含所有门店的Excel表格
- **下载模板**：获取标准导入表格格式

## 📌 使用建议

### 日常使用流程

1. **每天早上**：打开首页，查看战役头部数据，了解昨日战况
2. **查看PK榜**：看区县排名变化，找到需要重点关注的区域
3. **检查热力图**：看哪些门店掉队，及时跟进
4. **处理任务**：进入作战任务，完成今日任务
5. **检查AI内容工厂**：看内容生成进度

### 新品上市流程

1. 进入 **AI战略生成器**，填写产品信息
2. AI生成五大战略礼包，检查内容
3. 点击「启动30天新品战役」
4. 每天在首页跟踪战役进度
5. 战役结束后进入 **战役复盘** 总结经验
